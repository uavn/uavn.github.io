uavn.github.io
==============

GitHub Page

## Build

The site is assembled into `_site` with:

```sh
scripts/build-site.sh
```

External apps are not committed in this repository. During the build,
`scripts/fetch-external-app.sh` reads `scripts/external-apps.conf`, fetches the
latest configured branches, and places each app under `_site/<app>`.

Local and CI builds use a token by default. For local builds, create
`.env.local`:

```sh
EXTERNAL_APPS_TOKEN=...
```

Then run:

```sh
scripts/build-site.sh
```

If `.env.local` is absent, the script also accepts `EXTERNAL_APPS_TOKEN`,
`GH_TOKEN`, or `GITHUB_TOKEN` from the current shell, and will try
`gh auth token` when the GitHub CLI is logged in.

In GitHub Actions, add a repository secret named `EXTERNAL_APPS_TOKEN` with
read access to the external app repositories. CI uses that token automatically.

External app routes currently generated by the build:

- `musvis` from `uavn/audio-visualizer`
- `mapvis` from `uavn/mapvis`
- `movanova` from `uavn/nova-mova`
- `unicorn-noir` from `uavn/unicorn-noir`

## Games in this repository

Anything under `games/<name>/` with a `package.json` is built during
`scripts/build-site.sh` (`npm ci && npm run build`) and published at `/<name>`.
The build output and `node_modules` stay out of git.

- `games/medieval-drift` → `/medieval-drift`

## Photos

The Photos app (`/photos`) shows the film photos from
[Lomography](https://www.lomography.com/homes/artbonvic). Lomography is behind a
Cloudflare challenge and has no CORS, so the page can't read it live; instead it
reads `photos/lomography.json`, while the images themselves load straight from
Lomography's CDN.

To refresh the list, open https://www.lomography.com/homes/artbonvic/photos in a
browser, paste `scripts/lomography-sync.js` into the DevTools console, and save
the downloaded `lomography.json` over `photos/lomography.json`.

## Wallpapers

Originals live in `resources/wallpapers/`. The desktop uses resized copies:
`web/` (2560px) for the background and `thumbs/` (480px) for the picker. After
adding a wallpaper, generate both, e.g.:

```sh
sips -Z 2560 resources/wallpapers/NAME.jpg --out resources/wallpapers/web/NAME.jpg
sips -Z 480 resources/wallpapers/NAME.jpg --out resources/wallpapers/thumbs/NAME.jpg
```
